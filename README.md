# 📊 CodSoft Student Grade Calculator

A Java Console-Based Student Grade Calculator developed as part of the **CodSoft Java Programming Internship**.

This project calculates the total marks, average percentage, and final grade of a student based on marks entered for different subjects.

---

# 🚀 Features

- 📝 Enter Subject Marks
- ➕ Calculate Total Marks
- 📊 Calculate Percentage
- 🏆 Display Grade
- ✅ User-Friendly Console Output

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/geetika19396/CODSOFT_TASK2_STUDENT_GRADE_CALCULATOR.git
```

---

### Go to Project Folder

```bash
cd CODSOFT_TASK2_STUDENT_GRADE_CALCULATOR
```

---

### Compile

```bash
javac StudentGradeCalculator.java
```

---

### Run

```bash
java StudentGradeCalculator
```
